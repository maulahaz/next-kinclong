# UI Rules

- Mobile-first design
- Use Tailwind + shadcn only

## Color Rules

- MUST use defined mint color palette from PRD

## Buttons
- Always: icon + label
- Small buttons: icon only + tooltip

## Feedback
- Show toast on:
  - success
  - error

## Loading
- Button must show spinner on click

## Tables
- Actions column:
  - "..." menu
  - Options: Detail, Edit

## Destructive Actions
- Always show confirmation modal
